- **Shipped (2026-10-30):** the Author debrief editor. The Scenarios page (`/scenarios`) has a section per held role, like Home: Learners see what they can practice, Authors see each Scenario's debrief status and open its editor (`/scenarios/$scenarioId/debrief`). Authors fill in feedback guidance, Communication Criteria, and both Reflection Prompts, or press Generate a draft to load the labeled generated draft and edit it. The editor names the publisher only as "you" or "another Author", never a Member's email.

## Inherited limits to retain

- Slice 2: `last_admin` now fires when the only active admin tries to remove their own admin role; self-deactivation still returns `self_change` first. When two admins change each other at once, Convex re-runs the loser, which then fails the Institutional Admin role check, so exactly one change applies and an active admin always remains. The status is spare defense if the checks are reordered. A suspended Attempt's end message is the same for role removal and deactivation.
- Slice 1: `unavailable` for another institution's identity reveals that the identity is held elsewhere, though not where.
- #16: authorized review identifies Learners by roster email. Live Faculty review and live scope removal (group and availability) were shown on 2026-10-01.
- #15: automatic deletion merged through PR #29 (90 days after an Attempt ends, 30 days after an Active Attempt's last event; daily purge at 07:00 UTC). Run counts are stored but not shown in the UI. There is no per-Attempt notice of the deletion date, and no legal-hold or override path, per policy.
- #14 and debrief content: citations are checked for event existence, not semantic accuracy (a criterion rating can cite a real but irrelevant event); suggestions can be uncited; "performed incorrectly" is not in the word check; generated prompts are not checked for restating feedback; reflections do not inform feedback; the serving model is not logged.
- #13: the ending minimum counts every recorded Learner message.
- #11: actions are permitted while a reply is pending; the concluding observation repeats slightly.
- #10: Retry is hidden before 60 seconds; reply screening is deterministic and cannot detect a newly introduced symptom or history; blank messages or request IDs throw.
- #9: reopening an owned Attempt does not recheck availability.
